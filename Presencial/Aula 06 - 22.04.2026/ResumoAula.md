## ERP

- É um software que reúne todos os processos e informações de uma organização. Centralizado, ele conecta departamentos como finanças, vendas, recursos humanos, estoque e compras.
- Torna possível decisões a partir de dados
- Permite acesso a tudo, mas restringe ao usuário
- Permite automações mais facilmente
- Ele atua como base para digitalização
- Permite escalabilidade e competitividade
