# 📚 Integração Vertical e Horizontal

Repositório com todas as lições, atividades e trabalhos desenvolvidos na disciplina de Integração Vertical e Horizontal ministrada pelo professor Deivison Takatu, do curso de **Análise e Desenvolvimento de Sistemas**.


## 🎓 Sobre a Disciplina

A disciplina aborda estratégias de integração organizacional aplicadas a ambientes industriais e corporativos, com foco em:

* Integração Vertical
* Integração Horizontal
* Redes industriais e corporativas
* Planejamento estratégico
* Cadeia de suprimentos

## 📂 Estrutura do Repositório

```bash
📁 Integracao-Vertical-e-Horizontal
│
├── 📁 Aula-01
│
├── 📁 Aula-02
│
├── 📁 Aula-03
│
└── README.md
```

A organização está separada por aulas, e dentro de cada pasta estão as atividades correspondentes (relatórios, resumos, estudos de caso, etc.).

## 🎯 Objetivo do Repositório

Este repositório tem como objetivo:

📌 Organizar todas as atividades da disciplina

📌 Servir como material de estudo e revisão

📌 Demonstrar evolução acadêmica e técnica
